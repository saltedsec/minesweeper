# 💣 지뢰찾기

클래식 Windows 지뢰찾기의 분위기를 담아 만든 브라우저 게임입니다. 설치 없이 웹 브라우저에서 즐길 수 있습니다.

## 게임 소개

선택한 난이도의 격자에서 지뢰가 없는 칸을 모두 여세요. 숫자는 주변 8칸에 있는 지뢰의 수를 알려줍니다. 지뢰를 모두 피해서 안전한 칸을 열면 승리하고, 지뢰를 열면 게임이 끝납니다.

- **초급:** 9 × 9, 지뢰 10개
- **중급:** 16 × 16, 지뢰 40개
- **고급:** 30 × 16, 지뢰 99개
- 첫 클릭한 칸과 그 주변에는 지뢰가 배치되지 않습니다.
- 좌클릭으로 칸을 열고, 우클릭으로 `깃발 → 물음표 → 표시 없음`을 전환합니다.
- 열린 숫자 칸을 더블클릭하거나 마우스 양쪽 버튼으로 누르면, 주변의 깃발 수가 숫자와 일치할 때 남은 칸을 엽니다.
- 타이머와 남은 지뢰 수, 새 게임 버튼을 제공합니다. 클릭·폭발·승리 효과음과 간단한 애니메이션은 음소거 버튼으로 끌 수 있습니다.

## 어떻게 만들었나요

먼저 게임의 목표와 규칙, 화면 요소를 PRD로 정리했습니다. 구현 전에 PRD 요구사항을 단계별 계획으로 나누어 확인한 뒤, Vanilla JavaScript로 동작을 만들고 HTML·CSS·JavaScript 파일을 분리했습니다. 이후 난이도 선택, 코딩 입력, 효과음과 애니메이션을 추가하고 브라우저에서 각 난이도와 핵심 동작을 확인했습니다.

## freeform 버전과 비교했을 때

`freeform` 버전은 간단한 자연어 요청에서 출발해 기본 격자와 좌·우클릭, 타이머, 남은 지뢰 수를 빠르게 구현했습니다. `prd` 버전은 먼저 정리한 요구사항을 기준으로 첫 클릭 주변 안전 배치와 깃발·물음표 표시 순환까지 명시적으로 반영했습니다.

최종 버전은 요구사항을 빠뜨리지 않고 검토하기 쉬운 `prd` 흐름을 선택했습니다. 그 위에 난이도 선택, 더블클릭·양쪽 클릭 코딩, 효과음·애니메이션, 고전 Windows 스타일을 더해 완성했습니다.

## 실행 방법

- **온라인:** [GitHub Pages에서 플레이](https://saltedsec.github.io/minesweeper/) (저장소의 GitHub Pages가 `gh-pages` 브랜치 루트를 배포하도록 설정되어 있어야 합니다.)
- **로컬:** 저장소를 내려받은 뒤 `index.html`을 웹 브라우저에서 엽니다. 별도의 패키지 설치나 빌드 과정은 필요하지 않습니다.

## 커스터마이징한 부분

- 현대적인 카드형 화면 대신 회색 입체 버튼, 파란 제목 표시줄, 빨간 LED 카운터와 고전 지뢰찾기 숫자 색상을 적용했습니다.
- 초급·중급·고급 난이도 선택과 작은 화면에서의 고급 보드 가로 스크롤을 지원합니다.
- 첫 클릭 주변 안전 규칙, 빈 칸 연쇄 공개, 깃발·물음표 순환과 숫자 칸 코딩을 구현했습니다.
- 클릭·깃발 표시·폭발·승리에 간단한 효과와 생성형 효과음을 추가하고, 효과음을 켜고 끌 수 있게 했습니다.

구현 절차와 실습 안내는 [guide.md](./guide.md)를 참고하세요.
